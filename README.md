# Proyecto-INGSoftware-2026
Proyecto de la interfaz de ingeniería de software sobre el sistema de transporte de la UCV
## Caracteristicas Principales:
* **Modulo1-Registro de Usuarios:** Registro seguro de las credenciales del usuario 
* **Modulo2-Registro de Estudiante Ofertante:**  Registro de los datos de los estudiantes que tienen vehículo y ofertan rutas
* **Modulo3-Inicio de Sesión:**  Ingreso de los Usuarios al Sistema
* **Modulo4-Gestion de Perfil:**  Vista de las Credenciales, selección del icono de perfil y salida del sistema 
* **Modulo5-Ver Itinerarios y Rutas:** Visualización de las rutas y horarios a los que puede acceder el usuario
* **Modulo6-Gestión de Saldo:** Actualmente centrado en la visualización del Saldo que contiene actualmente el sistema
* **Modulo7-Gestión de Flota:** Gestión de las flotas del sistema manipulado por el o los administradores 
* **Modulo8-Gestion de Itinerarios:** Gestión de los itineraios del sistema manipulado por el o los administradores 
## Tecnologias y Herramientas
* **Lenguaje:** Java
* **Control de Versiones:** Git y Github
* **IDES:** Visual Estudio Code **Principal IDE** y NetBeans para el **desarrollo de las interfaces** con la librería Swing
## Estructura del Proyecto:
El proyecto esta estructurado por medio de carpetas o paquetes donde esta compuesta por
* **src** La carpeta que engloba las demás carpetas del proyecto
* **Módulos[1-8]** Paquete que contienen el código de los módulos previamente descritos en la parte superior, cada modulo esta compueto de las carpetas *Modelo,Vista,Controlador*
* **Modelo** Paquete que salva guarda o almacena los datos a procesar
* **Controlador** Paquete que contiene las funciones base y los controles de flujo que manjea cada modulo
* **Vista** Paquete que contiene la interfaz
* **data/Usuario** Paquete que contiene las clases usadas para el proyecto
* **Image** Carpeta que contiene las imagenes usadas para el desarollo de la interfaz
